# Research

Engineering evidence behind PrintMarshal's design decisions: the printer-model and
manageability research that the model catalogue and vendor plugins cite, the
enterprise-integration audit and its gap register, and the independent code review
with the response recording each verdict. The docs reference these files by name
(`docs/catalogue.md`, `docs/decisions.md`, `internal/plugins/README.md`).

Product-direction material (market analysis, commercial plans) is kept outside this
repository.
