What works with your printers today.

● Implemented SNMP v1/v2c/v3 · IPP/IPPS · mDNS · WS-Discovery

1. Discover printers and reconcile identity

PrintMarshal discovers printers across office VLANs and branch subnets without agents. Operators can run on-demand CIDR/IP scans, schedule background discovery, or enable passive multicast listeners for mDNS/DNS-SD and WS-Discovery.

Deduplication
Reconciles records by serial → UUID → lowercased MAC → IP address (internal/store/sqlite_devices.go). If an IP matches an existing record whose non-empty serial, UUID, or MAC differs, IdentityConflicts prevents merging so a different printer reusing an IP creates a separate record.
Operator fields
displayName, location, assetTag, and notes are stored separately from polled fields (discoveredName, discoveredLocation) and are never overwritten by polls.
Lifecycle states
Track printers across discovered, active, maintenance, and retired states, and organize devices into static or filter-based groups.

● Implemented RFC 3805 Printer-MIB · RFC 2790 Host-Resources · IPP

2. Monitor health, supplies, counters, and SNMP traps

Scheduled polling collects supply levels, input/output tray status, lifetime impression counters, and active Printer-MIB alerts (prtAlertTable), while an optional SNMP trap listener ingests real-time device fault notifications.

Consumables
Reads prtMarkerSuppliesTable and IPP marker-* attributes, recording history for 30-day sparklines and matching low supplies against spare inventory (GET /api/consumables/plan).
Counters
Captures total, mono, color, duplex, scan, and copy counters where reported by standard or vendor MIBs.
SNMP traps
Rate-limited UDP trap receiver (PM_TRAP_ENABLED, default port 1162, configurable source CIDR allowlist trap.allowedSources and per-IP trap.ratePerMinute).
● Implemented ◐ Device-Dependent Remediation

3. Audit security posture, certificates, and credentials

PrintMarshal evaluates printers against the built-in 14-item Baseline policy or custom policies across the 84-key canonical settings catalog (43 security-tagged keys). Active assessments also probe management/print ports and inspect TLS handshakes.

Policy scoring
Supports 8 operators (eq, ne, gte, lte, in, notIn, set, unset) and severity weights (critical = 3, high = 2, medium = 1, low = 0.5). Unreadable keys return unknown and are excluded from the score denominator.
Certificates
Generates RSA-2048 CSRs (POST /api/devices/{id}/csr) and enrolls via internal CA, EST (/.well-known/est/simpleenroll), or SCEP. Raises warning alerts at ≤ 30 days and critical alerts at ≤ 7 days or expired (internal/security/certs.go). Physical installation requires a vendor CertificateInstaller driver or the printer web UI.
Rotation
Rotates snmpCommunity and adminPassword (internal/security/rotate.go): stages the new encrypted credential first, writes via SecurityWriter / ConfigWriter, deletes the staged credential on clean refusal, keeps it with a warning on ambiguous timeouts, and verifies snmpCommunity by polling.

◐ Device-Dependent 84-Key Catalog · Dry-Run · Read-Back · Drift

4. Preview configuration diffs, verify writes, and detect drift

PrintMarshal normalizes device configuration into an 84-key canonical settings catalog across 10 areas (identity, network, protocols, security, energy, trays, panel, print, scan, other in internal/model/settings_catalog.go).

Dry-run diff
Reads live values from each target device and shows which keys already match, which will be written, and which are unsupported before touching hardware.
Standard writes
Standard SNMP writes MIB-II sysName, sysLocation, and sysContact (internal/driver/snmp/config.go). Standard IPP writes attributes listed in the printer's printer-settable-attributes-supported via authenticated Set-Printer-Attributes with TLS leaf fingerprint pinning (internal/driver/ipp/config.go).
Drift & revert
Compares snapshots across polls to alert on unexpected changes and stores prevValues on every write job for one-click rollback (POST /api/config/writes/{id}/revert).
◈ Simulator-Only Delivery ◌ Physical Push Requires Driver

5. Stage firmware and inspect the 495-model catalog

Upload firmware images to the local content-addressed repository (verified by SHA-256), define minimum version rules per model, and test staged rollout campaigns against pm-sim.

Delivery scope
The built-in firmware HTTP uploader (POST /fw-sim) only targets loopback simulator endpoints (127.0.0.1 / localhost). Pushing firmware to physical printers requires implementing driver.FirmwareDriver.
Research catalog
Includes a 15-vendor, 126-family, 495-model enterprise research catalog (0 physically validated out of the box) that separates Documented vendor routes from Observed live driver evidence and operator lab qualification.

Operations, Audit & Optional Host Queue Bridge

Reports, RBAC, SIEM export, and local CUPS queues.

PrintMarshal includes multi-provider authentication, append-only audit logging, scheduled webhooks, and an optional Linux local CUPS queue add-on.

RBAC & Enterprise Auth ● Implemented

Three built-in roles (admin, operator, viewer) across local bcrypt accounts, OIDC (Authorization Code + PKCE), SAML 2.0, LDAP/Active Directory, RADIUS PAP, and SHA-256 hashed API tokens with optional groupIds scope.

Reports, Webhooks & SIEM ● Implemented

Export JSON or CSV reports for utilisation, fleet-health, supplies, alerts, and firmware (note: /api/reports/compliance is a placeholder; live compliance data is served at /api/security/compliance). Forward append-only audit events to RFC 5424 syslog (udp/tcp/tls), JSON-lines files, HTTP SIEM collectors, or HMAC-SHA256 webhooks.

Optional Local CUPS Add-on ◐ Off by Default

Defined in internal/printprovider/ (docs/print-provider.md). When enabled on a Linux host with CUPS tools (lpadmin, lpstat, cupsenable, cupsaccept), it plans, dry-runs (dryRun: true by default), creates/updates, and removes local CUPS queues (pm- prefix) or publishes IPP Everywhere URIs (ipp-everywhere-list) for discovered IPP printers. It never modifies a printer, and PrintMarshal does not perform job accounting, quotas, or pull-print release.
