# PrintMarshal — Frequently Asked Questions (`site/faq/index.html`)

1. **Which printers work with PrintMarshal today?** Standards SNMP (v1/v2c/v3), IPP/IPPS, and eSCL printers, plus 13 compiled-in vendor plugins (HP read-only PML/LEDM enrichment, Ricoh/Canon probe-gated private MIB counters, and 10 brand/model/serial normalisers).
2. **Does appearing in the 126-family Device Model Catalogue mean a printer is validated?** No. All 126 families (495 base model IDs across 15 brands) ship as `research_candidate_unvalidated` (`0` physically validated in the shipped catalog). Documented, Observed, and Unknown remain separate.
3. **Why do some security policy checks show "unknown" instead of pass or fail?** Unreadable settings over standards SNMP/IPP are recorded as `unknown` and excluded from the compliance score denominator rather than assumed compliant.
4. **Which settings can PrintMarshal actually write to a printer today?** Standards `snmp` writes 6 MIB-II/Printer-MIB keys (`sysName`, `sysLocation`, `sysContact`, `prtGeneralPrinterName`, default input tray, default marker); standards `ipp` writes location, info, organization, organizational unit, and `*-default` print attributes when `Set-Printer-Attributes` is supported. No real-vendor `ConfigWriter`, `SecurityWriter`, `CertManager`, or `FirmwareUpdater` ships today.
5. **What is the difference between certificate enrollment and certificate installation?** Enrollment (SCEP, EST, ACME DNS-01) is implemented; device installation requires a `CertManager` driver (none shipped for real vendors), and auto-renewal is not implemented.
6. **Does PrintMarshal update firmware on physical printers?** Artifact SHA-256 verification and canary/wave campaigns are implemented, but firmware delivery (`fwsim`) is simulator-only (`PM_FIRMWARE_SIM_TARGETS`).
7. **Is PrintMarshal a print server or virtual print queue?** No. It provides optional IPP/IPPS hold/release for RFC 3998 printers and PaperCut/uniFLOW CSV/JSON accounting import.
8. **Can I run multiple PrintMarshal server replicas for high availability?** Run a single active server process per database.
9. **How can I test PrintMarshal without touching real office printers?** Use `cmd/pm-sim` on `127.0.0.1` with the SNMP walk fixtures in `testdata/fixtures/`.
