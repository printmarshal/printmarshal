Everything a fleet needs, nothing it does not

PrintMarshal manages devices, not print jobs. It is not a print-accounting, quota or pull-printing tool. It is the console that keeps the printers themselves discovered, healthy, configured and secure.

Discovery and inventory

Zero-config mDNS and WS-Discovery plus bounded scans of addresses, ranges and subnets. Devices are identified over SNMP, IPP and eSCL and de-duplicated by serial, UUID and MAC.

Monitoring and alerts

Scheduled polls of status, supplies, trays, counters and firmware; an SNMP trap listener; alerts with severity, acknowledgement and notifications to Slack, Teams, webhooks or email.

Configuration management

Normalised configuration documents, profiles, drift detection and gated writes that are dry-run by default and audited when they are not.

Security and certificates

Policies of desired security settings, assessment and remediation, staged credential rotation, and certificate enrolment over SCEP and EST with expiry tracking.

Firmware campaigns

A fleet-wide version inventory and staged campaigns with waves, confirmation gates, pause and resume, run only through drivers that implement delivery.

Identity and access

Local accounts with viewer, operator and admin roles; OpenID Connect, SAML, LDAP or Active Directory bind and RADIUS; scoped API tokens for automation.

Built for operators

  • Read-only by defaultDiscovery and polling only read. Nothing is written to a printer without an explicit operator action.
  • Dry run firstApply, remediate, rotate, enrol and firmware delivery rehearse before they act, and the real write is a separate, deliberate step.
  • Audited writesEvery write records who, what, where and the verified result, and the audit trail exports to your SIEM.
  • Vendor-agnosticStandards drivers cover compliant devices; vendor plugins enrich what they can and say honestly what they cannot.
  • Self-hostedOne binary with an embedded UI, SQLite or PostgreSQL, Docker, Helm or systemd. Your data stays on your network.
  • Open sourceApache-2.0 licensed, with the administrator and developer wiki in the same repository.

Get started in a minute

Run the container, open the UI, add a read credential and discover your first subnet. The full installation guide covers Docker Compose, Helm and systemd.

git clone https://github.com/printmarshal/printmarshal.git
cd printmarshal
make docker                      # builds printmarshal:latest (UI + service)
docker compose -f deploy/docker-compose.yml up -d
# or, without Docker: make web && make build && PM_ADMIN_PASSWORD=change-me ./bin/printmarshal
